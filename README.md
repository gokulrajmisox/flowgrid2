### 🔧 Technical Patches

| Patch | Purpose |
|:---|:---|
| **Error Suppression** | Catches Three.js parsing errors from placeholder `.buf` model files |
| **Preloader Timeout** | Forces page ready after 8 seconds if assets fail to load |
| **Scroll Reset** | Resets scroll position to top on page load |
| **Route Fix** | Strips `.html` extensions so SPA router recognizes pages correctly |
| **Redirect Block** | Prevents the router from redirecting to origin on unknown routes |
| **Menu Fallback** | Toggle + navigation fallback if the original JS init fails |

## 🚀 Getting Started

### Prerequisites

- Any modern browser with **WebGL** support (Chrome, Firefox, Edge, Safari)
- **One** of: Python 3.x / Node.js / PHP / any static file server

> [!IMPORTANT]
> The site **must** be served via HTTP — opening `index.html` directly as a `file://` will **not work** because it uses ES modules and `fetch()` requests.

### 📥 Download / Clone

**Option 1 — Git Clone (recommended)**
```bash
git clone https://github.com/Tcode-Motion/flowgrid-clone.git
cd flowgrid-clone
```

**Option 2 — GitHub CLI**
```bash
gh repo clone Tcode-Motion/flowgrid-clone
cd flowgrid-clone
```

**Option 3 — Download ZIP**
1. Click the green **`<> Code`** button at the top of this repo
2. Click **`Download ZIP`**
3. Extract and open a terminal in that folder

---

## 💻 Run Locally

> [!IMPORTANT]
> You **cannot** just double-click `index.html`. The site uses ES modules and `fetch()` calls that require a proper HTTP server — pick any one method below.

### Method 1 — 🐍 Python (Zero install, works on all OS)

```bash
# Navigate into the project folder first
cd flowgrid-clone

# Python 3 (most common)
python -m http.server 8000

# Python 2 (legacy)
python -m SimpleHTTPServer 8000
```

Then open **http://localhost:8000** in your browser. 🎉

---

### Method 2 — 📦 Node.js (`npx serve`)

```bash
cd flowgrid-clone
npx serve .
```

> No global install needed — `npx` downloads `serve` on demand.
> Default port is **3000** → open **http://localhost:3000**

---

### Method 3 — 📦 Node.js (`live-server` with auto-reload)

```bash
npm install -g live-server
cd flowgrid-clone
live-server
```

The browser opens automatically and refreshes on every file save. Great for development!

---

### Method 4 — 🐘 PHP

```bash
cd flowgrid-clone
php -S localhost:8000
```

Open **http://localhost:8000**

---

### Method 5 — 🪟 Windows One-Click (Batch Script)

A `start_server.cmd` file is included in the repo root. Just **double-click** it — it starts a Python server and opens your browser automatically.

```bat
:: What start_server.cmd does internally:
cd /d "%~dp0"
start http://localhost:8000
py -m http.server 8000
```

---

### Method 6 — 🆚 VS Code Live Server Extension

1. Install the **[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)** extension in VS Code
2. Open the `flowgrid-clone` folder in VS Code
3. Right-click `index.html` → **"Open with Live Server"**
4. The site opens at **http://127.0.0.1:5500**

---

### 🪟 Windows Quick Start (PowerShell)

```powershell
cd "C:\path\to\flowgrid-clone"
py -m http.server 8000
# Open http://localhost:8000 in Chrome
```

### 🐧 Linux / 🍎 macOS Quick Start

```bash
cd ~/flowgrid-clone
python3 -m http.server 8000
# Open http://localhost:8000
```

---

### ✅ Verifying It Works

Once the server is running, visit **http://localhost:8000** — you should see:

1. **A full-screen preloader** counting from 0 → 100%
2. **A smooth reveal** into the 3D WebGL homepage
3. **An interactive cursor** (custom dot + ring) following your mouse
4. **Purple accents** on scroll bar, buttons, and hover states

> [!TIP]
> If the page is blank or shows errors: make sure you started the server **from inside** the `flowgrid-clone` folder, not from a parent directory.

## 🤝 Contributing

Contributions are welcome! Whether it's a bug fix, a new feature, or a docs improvement — every PR is appreciated. 🙌

### 🔁 How to Contribute

**Step 1 — Fork the repository**

Click the **Fork** button at the top-right of this page to create your own copy.

**Step 2 — Clone your fork locally**
```bash
git clone https://github.com/<your-username>/flowgrid-clone.git
cd flowgrid-clone
```

**Step 3 — Create a new branch**

Always work on a new branch — never commit directly to `main`.
```bash
git checkout -b feature/your-feature-name
# Examples:
# git checkout -b fix/mobile-cursor-bug
# git checkout -b feature/dark-mode-toggle
# git checkout -b docs/improve-readme
```

**Step 4 — Make your changes**

The key files to edit:

| File | What to edit |
|:---|:---|
| `custom.css` | Visual styles, colors, animations |
| `custom.js` | Cursor logic, scroll behavior, JS enhancements |
| `patch.js` | Routing, loading, and compatibility fixes |
| `index.html` / `about.html` / `projects.html` | Page structure & markup |
| `projects/*.html` | Individual project pages |

**Step 5 — Test your changes locally**
```bash
python -m http.server 8000
# Open http://localhost:8000 and verify everything works
```

**Step 6 — Commit your changes**
```bash
git add .
git commit -m "feat: add dark mode toggle to header"
# Commit message prefixes:
# feat:     new feature
# fix:      bug fix
# docs:     documentation change
# style:    formatting / visual-only change
# refactor: code improvement with no behavior change
```

**Step 7 — Push and open a Pull Request**
```bash
git push origin feature/your-feature-name
```

Then go to your fork on GitHub and click **"Compare & pull request"**.

---

### 📋 Contribution Guidelines

- 🧹 **Keep it clean** — follow the existing code style (2-space indentation, clear variable names)
- 📝 **Describe your PR** — explain what you changed and why
- 🧪 **Test before submitting** — verify on at least Chrome and Firefox
- 🚫 **Don't break existing features** — preloader, WebGL scene, cursor, and routing must still work
- 💬 **Open an issue first** for large changes — let's discuss before you invest time

### 💡 Ideas for Contributions

- 🐛 Bug fixes (mobile layout issues, audio edge cases, etc.)
- 📱 Improved mobile / touch support
- ♿ Accessibility improvements (keyboard nav, ARIA labels)
- 🌍 More project detail pages
- 🎨 Alternative color themes (e.g. neon green, cyber red)
- 📄 Better documentation or code comments
- ⚡ Performance optimizations

## ❓ FAQ

**Q: The page is blank when I open `index.html` directly.**
A: You must serve the project through an HTTP server. See [Run Locally](#-run-locally) above.

**Q: The 3D scene doesn't load / I see WebGL errors.**
A: Make sure your browser and GPU support WebGL. Visit [webglreport.com](https://webglreport.com) to check. Try Chrome for best compatibility.

**Q: Audio doesn't play.**
A: Browsers require a user interaction before playing audio. Click the sound toggle button in the top-right corner of the site.

**Q: I get a CORS error in the console.**
A: This happens when you open the file directly (`file://`). Always use a local HTTP server.

**Q: The preloader gets stuck.**
A: `patch.js` includes an 8-second timeout that forces the site to reveal itself. If it's consistently stuck, check the browser console for asset loading errors.

**Q: Can I use this for my own portfolio?**
A: Yes! This is open for educational use. Please keep the disclaimer and credit the original [flowgrid studio](https://flowgrid.co).
